# FluentFluid — Optical flow dataset of Gas
![dateset](image74.gif)

## Description
The gas concentration images and corresponding velocity fields we obtained through calculations using FDS software and algorithms are limited by the upload speed of the network. 
We provide **2,490** image pairs along with their corresponding optical flow files. If you require more data, please send me a message specifying your purpose. 
We strongly support you using this dataset for scientific research.

## Applicable scenarios
- Machine vision gas detection
- Fluid mechanics analysis
